# customer_behavior_analysis
Data Analytics project showcasing customer behavior analysis using python, SQL, PowerBI

Customer Behavior Data Analytics Project
Overview

This project focuses on analyzing customer behavior and extracting meaningful business insights from a raw dataset. The project covers the complete data analytics process, from data loading and cleaning to SQL analysis, Power BI visualization, reporting, and presentation.

Dataset

The project uses a customer behavior dataset containing information related to customer purchases, products, ratings, and other customer-related attributes.

Project Steps
Loaded the dataset into Python using Pandas.
Performed Exploratory Data Analysis (EDA) to understand the dataset and identify patterns.
Cleaned and preprocessed the data by handling missing values, duplicates, data types, and inconsistencies.
Loaded the cleaned data into a relational database.
Performed SQL queries to analyze customer behavior and generate business insights.
Created an interactive Power BI dashboard to visualize key findings.
Prepared a detailed data analytics report based on the analysis.
Created a project presentation using Gamma.
SQL Analysis

SQL was used to perform various analyses such as:

Customer behavior analysis
Product performance analysis
Average product ratings
Purchase patterns
Category-wise analysis
Identifying top-performing products

SQL analysis was performed using PostgreSQL, MySQL, and/or SQL Server.

Power BI Dashboard

An interactive Power BI dashboard was created to present the key findings through KPIs, charts, filters, and other visualizations.

The dashboard helps users understand customer behavior, product performance, ratings, and important trends.

Results

The analysis provided insights into customer purchasing behavior, product performance, ratings, and other important business patterns.

The results were presented through the Power BI dashboard, analytical report, and project presentation.

How to Run
Clone or download the project repository.
Install the required Python libraries:
pip install pandas numpy matplotlib seaborn sqlalchemy pymysql
Open the Jupyter Notebook.
Load the dataset using Pandas.
Run the data cleaning and EDA steps.
Set up the required database and load the cleaned data.
Execute the SQL queries.
Open the Power BI .pbix file and refresh the data if required.
Refer to the report and presentation for the final analysis and findings.
